Production Runner

Private · built for ifm statmath
RoleFull-stack developer & Scrum Master
Team6 people
TimelineSept 2025 – Feb 2026
ContextProgrammierpraktikum, Uni Siegen

Two players race against a Pac-Man-style production line while a model trains or a plan gets calculated in the background — turning dead time on the factory floor into a two-minute game. I worked on both ends: the Angular front end that renders the game on a Canvas, and the backend that keeps score in real time and survives a reboot.

Angular 17TypeScriptCanvas API ASP.NET Core 8C#SignalR PostgreSQLDockerRaspberry Pi
  • Built the two-player game loop and input handling for physical arcade buttons wired into a Raspberry Pi.
  • Built the ASP.NET Core backend; live score and game-state updates pushed over SignalR instead of polling.
  • Persisted high scores in PostgreSQL so the leaderboard survives restarts and power cycles.
  • Packaged the whole stack in Docker so it deploys the same way on a dev laptop and the arcade cabinet.
  • Ran the team as Scrum Master — daily stand-ups, sprint reviews, retros — alongside writing code.
  • Presented the finished cabinet to a jury and live audience at "THE SUMMIT" in Siegen.

Werkly

In active development
RoleSolo — concept, frontend, backend
Started2025
PlatformAndroid · Web

A Flutter app that helps Werkstudenten in Germany find jobs that actually match their city, schedule and German level — not just their keywords. It scores each listing against your profile, tracks the applications you've sent, plots jobs on a map, and can answer questions about a posting through a Gemini-powered assistant.

FlutterDartSupabase PostgreSQLEdge FunctionsOpenStreetMap Gemini AI
  • Compatibility scoring that ranks listings against a student's profile instead of a plain keyword search.
  • Smart filters — city, remote share, weekly hours, required German level — on top of the scoring.
  • Profile and CV tools plus application tracking, so a search doesn't end at "bookmarked and forgotten."
  • Map view built on OpenStreetMap to browse jobs by commute, not just by list.
  • Supabase backend — Postgres plus Edge Functions — with an optional Gemini-based career assistant that answers questions about a posting.
  • Interface ships in French, German and English.
